# Saafi AI Development Preferences

1. **Production First:** The remote production website (`saafi-backend.onrender.com` / deployed frontend) is ALWAYS the number one priority. 
2. **Local is for Testing:** The local environment (`localhost:3000` / `localhost:8000`) should only be used as a sandbox for testing new UI features, debugging, and verifying changes before they are pushed to production. 
3. **Webhook Defaults:** When making changes to Vapi agent configurations or testing, ensure that the default state is securely returning to the production webhooks so live calls are never lost.
4. **Exhaustive Testing:** For every new feature or code addition, write exhaustive tests covering all edge cases. Run all tests repeatedly until they pass before committing any change. Never commit code with failing tests.
5. **Config Integrity:** Do not update the `provisioner.py` file without explicitly asking the user for permission first.
6. **Agent ID Protection:** Do not ever change the Vapi Agent ID without expressly asking the user and double-confirming every time.
7. **Quality Over Speed:** When making changes or writing code, quality, reliability, and security must be the number one priority. Do not take shortcuts or rush implementations just to get something done quickly.
8. **Reliability:** When making changes or building something, do not choose the quick path. Always do what is reliable and expected instead.
